You are a Blockchain domain expert.
OSC means On-chain State Constraints.
SPC means Specific Process Constraints.
For each OSC or SPC parameter in the input list:

1. If constraint == "OSC":
   - legal is a function that must return a value that **exists or will exist on-chain** (slot, blockhash, pubkey, etc.)
   - illegal is a function that must return a value that **violates** the on-chain existence rule (out-of-range, fake, expired, negative, etc.)

2. If constraint == "SPC":
    output **chain_variants**: legal_A, illegal_A, legal_B, illegal_B, …, legal_D, illegal_D:
    - legal is a function that must return a value that is **correctly produced by the full chain of specific processes** (key-gen → sign → serialize → encode)
    - illegal is a function that must return a value that **breaks at least one step** in the chain (fake key, unsigned, wrong encoding, expired hash, etc.)
    - A, B, C, D are the **semantic steps** described in the reason field
    - Each step must be a **runnable function** that can be chained together
    - The final function (D) must consume the output of C and return the final parameter value

Local dev chain (127.0.0.1:8899) is the target environment.
No comments, no error handling, only the function body.

OSC Example:
```
{
    "tools": [
    {
        "path": "object.minContextSlot",
        "constraint": "OSC",
        "imports": [
            "requests",
            "os"
        ]
        "legal": "def get_min_context_slot() -> int:\n    import os, requests\n    rpc = os.getenv(\"SOLANA_RPC\", \"http://127.0.0.1:8899\")\n    resp = requests.post(rpc, json={\"jsonrpc\": \"2.0\", \"id\": 1, \"method\": \"getSlot\"}, timeout=10)\n    return resp.json()[\"result\"]",
        "illegal": "def illegal_minContextSlot():\n    return -1"
    }
    ]
}
```

SPC Example:
```
{
  "tools": [
    {
      "path": "transaction",
      "constraint": "SPC",
      "imports": ["requests", "solders.message", "solders.keypair", "solders.hash", "solders.transaction"],
      "chain_process": {
        "build_message": {
          "legal": "def build_message_legal():\n    from solders.message import Message\n    from solders.hash import Hash\n    from solders.keypair import Keypair\n    from solders.system_program import TransferParams, transfer\n    ix = transfer(TransferParams(from_pubkey=Keypair().pubkey(), to_pubkey=Keypair().pubkey(), lamports=1_000_000))\n    return Message.new_with_blockhash([ix], Keypair().pubkey(), Hash.from_string(get_latest_blockhash()))",
          "illegal": "def build_message_illegal():\n    from solders.message import Message\n    from solders.hash import Hash\n    return Message.new_with_blockhash([], Keypair().pubkey(), Hash.from_string('11111111111111111111111111111111'))  # expired blockhash"
        },
        "sign_message": {
          "legal": "def sign_message_legal(msg):\n    from solders.keypair import Keypair\n    from solders.hash import Hash\n    keypair = Keypair()\n    msg.sign([keypair], Hash.from_string(get_latest_blockhash()))\n    return msg",
          "illegal": "def sign_message_illegal(msg):\n    return msg  # unsigned → breaks wire format"
        },
        "serialize_message": {
          "legal": "def serialize_message_legal(signed):\n    return bytes(signed)",
          "illegal": "def serialize_message_illegal(signed):\n    return b'\\x00garbage'  # not a valid wire format"
        }
      }
    }
  ]
}
```
